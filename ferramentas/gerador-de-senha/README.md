Problema a solucionar: quero ter senhas únicas e fortes para cada serviço. Além disso quero conseguir utiliza facilmente as senhas no meu laptop, smartphone e tablet.

Solução: Cofre de senha com senha mestra que gera e armazena senhas.

Risco 1: ponto único de falha. Se alguém acessar o cofre, terá acesso a todas as senhas.
Mitigação: Uso de senha mestra com pelo menos 16 posições. Uso de segundo fator de autenticação ao acessar o cofre: aplicativo de autenticação, geração de código por e-mail, uso de passkey, uso de chave física.

Risco 2: Se perder a senha mestra, perde acesso a todas as senhas
Mitigação: armazenar a senha em local seguro que caso esqueça possa ser recuperada.
